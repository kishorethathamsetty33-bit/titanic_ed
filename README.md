Titanic Dataset – Data Cleaning & Visualization

Project Overview

This project focuses on cleaning and analyzing the Titanic dataset using Python.
The dataset was cleaned and visualized to understand passenger survival patterns.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Data Cleaning

- Checked missing values
- Handled missing data
- Checked duplicate records
- Corrected data types
- Prepared the dataset for analysis

Data Visualization

Created visualizations to analyze:

- Survival rate
- Survival by gender
- Survival by passenger class
- Age distribution
- Fare distribution
- Passenger class distribution
- Correlation between numerical features

Key Insights

- Survival varied by gender.
- Passenger class had an impact on survival.
- Age and fare showed differences between passengers who survived and those who did not.
